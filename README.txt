HOW TO ADD DOODLES: Save each original drawing to images/doodles/ (create this folder). Edit doodles.js and add an entry to the doodles array with number, title, image path and the URL of the ORIGINAL Facebook post. Example:
{ number: 1, title: "Little Miss Kiwi", image: "images/doodles/001.webp", facebookUrl: "https://www.facebook.com/your-post-link" }
